# 💎 Jewelry Website

A responsive jewelry website developed using **HTML5, CSS3, and JavaScript**. 
The project showcases a modern jewelry store with multiple pages and a clean, user-friendly interface.

## Features

- Responsive homepage
- About Us page
- Contact page
- Sale page
- Interactive user interface using JavaScript
- Clean and organized design using CSS

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 📂 Project Structure

```
Jewelry_Website/
│── index.html
│── about.html
│── contact.html
│── sale.html
│── style.css
│── script.js
│── images/
```

## Git Workflow

This project also demonstrates the use of **Git Branching**.

- Created a separate branch named **sale**.
- Developed the **Sale** page in the `sale` branch.
- Merged the `sale` branch into the `main` branch after successful development.
- Pushed the updated project to GitHub.

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
